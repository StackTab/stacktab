FAQ

Common questions

How do I save a path?

Open the Path Jump popup (click the extension icon or press Alt+P), navigate to the URL you want to save, then click "Save current path". Give it a label and it will appear in your palette.

Does it work with ports (localhost:3000)?

Yes. Path Jump treats the full origin (protocol + hostname + port) as the "environment". You can save environments like http://localhost:3000, http://localhost:8080, etc. as separate entries.

Are my saved paths synced between devices?

Yes! Your saved endpoint configuration can automatically sync through your Chrome profile using Chrome's built-in storage system. This keeps your endpoints available on any device where you are logged into Chrome.

Does it read the content of the pages I visit?

No. Path Jump only reads the URL of the active tab when you trigger the extension. It never reads page content, cookies, or any other data.

Can I change the Alt+P shortcut?

Yes. Go to chrome://extensions/shortcuts (or edge://extensions/shortcuts) and set your preferred key combination.
