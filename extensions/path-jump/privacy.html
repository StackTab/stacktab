Privacy Policy for Path Jump

Last Updated: October 10, 2026

1. Overview & Single Purpose

Path Jump (offered by StackTab) has a single purpose: to allow users to save URL path shortcuts and quickly navigate or transpose paths across domains and development environments directly in Google Chrome.

2. Zero Data Collection Policy

Path Jump does not collect, log, track, or transmit any user data:

  • No External Network Requests: Path Jump does not make network calls to external analytical servers or database endpoints.
  • Confidentiality of Routes: All your custom internal routes, endpoints, query parameters, and environment mappings stay strictly in your browser's local storage.
  • Zero Tracking or Cookies: We do not inject cookies, ad trackers, or third-party monitoring code.

3. Technical Permissions Justification

Path Jump requests minimal browser permissions required for its operation:

Permission How It Is Used
activeTab Invoked strictly upon user command (clicking the extension or triggering Alt+P) to read the active tab's domain and navigate to the selected path. Never runs in the background across passive browsing.
storage Used to persist your bookmarked paths, custom tags, and environment mappings locally in Chrome extension storage.

4. Third-Party Sharing

Because Path Jump operates locally without external data ingestion, we do not share, sell, trade, or transfer any user data to third parties under any circumstances.

5. Compliance with Store Policies

Path Jump strictly complies with the Google Chrome Web Store Developer Program Policies, Limited Use requirements, and Manifest V3 security guidelines, as well as Microsoft Edge Add-ons policies.
