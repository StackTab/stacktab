# StackTab

**Browser tools that stay out of the way.**
StackTab provides focused, local-first browser extensions for power users and developers. Zero telemetry, zero background drain, 100% on-device.

## 🚀 Included Extensions

### [TabIntel](https://hetgandhi781.github.io/stacktab-website/extensions/tabintel/index.html)
Find and close duplicate tabs, search across all open tabs, and reclaim lost RAM — in milliseconds.
* **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/tabintel-%E2%80%94-duplicate-tab/nlgfdajjjfdegnlgbhfmnpbejlkodfpa) | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/tabintel-%E2%80%94-duplicate-tab-/fcmbhdagmkmeladpfmdbokainmglfplb)

### [Path Jump](https://hetgandhi781.github.io/stacktab-website/extensions/path-jump/index.html)
Save URL paths and jump to them instantly — swap between localhost, staging, and production with one keystroke.
* **Install:** [Chrome Web Store](https://chromewebstore.google.com/detail/path-jump-%E2%80%93-url-path-navi/fbomikgcaliadepbcadbajcaghiamadk) | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/path-jump-%E2%80%93-url-path-navi/cmipbnlnjjcbahcfjdpcniniapegjiih)

## 🛡️ Privacy & Security
We believe in 100% local-first processing. None of your data, browsing history, or URLs are ever transmitted to any external server.
